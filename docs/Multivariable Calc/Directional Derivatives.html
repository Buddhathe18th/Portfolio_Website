Directional Derivatives

We've covered already how to take the partial derivative of a multivariable function as how much the function increases for a step in the direction of the input. The question now is how can we find how taking a step in the \(\overrightarrow{v}\) direction will impact the value of the function. We'll call this the directional derivative of a function \(f\) with respect to a vector \(\overrightarrow{v}\). We denote this as \(\nabla _{\overrightarrow{v}}f\) or \(\frac{\partial f}{\partial \overrightarrow{v}}\)

We know that if we take a very small step in the direction of the vector \(\begin{bmatrix}2\\1\end{bmatrix}\), the step in the x direction would still be twice the step in the y direction. Therefore, we must use proportions and the directional derivative would be \(2\cdot \frac{\partial f}{\partial x} + 1\cdot \frac{\partial f}{\partial x}\). The only issue is that what if we tried to find the directional derivative in the direction of vector \(\begin{bmatrix}4\\2\end{bmatrix}\)? We know that this vector is the same direction as the previous vector, but instead, the directional derivative is twice as large. Therefore, we must only use unit vectors.

Now let's say we have a unit vector \(\overrightarrow{v}=\begin{bmatrix}v_1\\v_2\\\dots \\v_n\end{bmatrix}\). Then, if we want to find the directional derivative of a function \(f\) with inputs \(x_1,x_2,\dots,x_n\) in the direction of \(\overrightarrow{v}\), we know we want to find \(v_1\cdot \frac{\partial f}{\partial x_1}+v_2\cdot \frac{\partial f}{\partial x_2}+\dots+v_n\cdot \frac{\partial f}{\partial x_n}\). To those with a keen eye, you'll notice this looks a lot like the cross of product of two vectors, and we know one seems to be \(\overrightarrow{v}\). Then what's the second vector? It's the gradient of \(f\)! Therefore, the directional derivative of a function \(f\) with respect to vector \(\overrightarrow{v}\) is \(\nabla _{\overrightarrow{v}}f=\nabla f \cdot \overrightarrow{v}\)
